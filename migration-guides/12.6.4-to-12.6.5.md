# Migration Guide: 12.6.4 → 12.6.5

## Overview

| Category | Details |
|---|---|
| **Breaking Changes** | None |
| **New Features** | None |
| **Bugfixes** | The email-verification link derives the app URL from `baseUrl` instead of pointing at `http://localhost:3001` when `appUrl` is not set (§1) |
| **Migration Effort** | None |

12.6.5 is a patch on the 12.6 line, published under the dist-tag `latest-12.6`. The same fix ships in 12.8.0 (`latest`)
and 11.44.0 (`latest-11`). Those two releases also refuse objects at primitive route parameters and drop non-string
cookies (DEV-4144); that change alters behaviour and therefore stays out of a patch — it reaches the 12.6 line through
12.8.0 (`migration-guides/12.6.x-to-12.7.x.md`, then `12.7.x-to-12.8.x.md`).

## Quick Migration

```bash
pnpm add @lenne.tech/nest-server@12.6.5
pnpm run update   # nest-server-starter based projects
pnpm run build
pnpm test
```

**Vendor mode**: `/lt-dev:backend:update-nest-server-core --target 12.6.5` (without `--target` the updater syncs to the
latest tag, which is on a newer line).

## 1. The verification link follows the app URL (DEV-4140)

**Why:** a relative `betterAuth.emailVerification.callbackURL` (the default `/auth/verify-email`) was resolved against
`appUrl || 'http://localhost:3001'`. A deployed stage without `NSC__APP_URL` therefore mailed a verification link to
localhost, although `NSC__BASE_URL` names the app and the password-reset link already derived it from there.

**What changed:** the link uses the same resolver as the reset link — explicit `appUrl`, the localhost default in
`local` / `ci` / `e2e`, else derived from `baseUrl` (`https://api.example.com` → `https://example.com`) unless
`cors.deriveAppUrl` is `false`. When nothing resolves, the mail keeps Better-Auth's own link to the API (token sealed)
and the service warns once.

**Your project:** nothing. `NSC__APP_URL` still wins where it is set.
`CoreBetterAuthEmailVerificationService.buildFrontendVerificationUrl()` now returns `string | undefined`; an override
that returns a string stays compatible.
